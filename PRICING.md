# Pricing pilote

## Founding Kitchen — premier restaurant

- Setup et paramétrage : 490 EUR HT
- Abonnement : 39 EUR HT / mois
- 1 établissement
- Jusqu'à 300 analyses photo / mois pendant la phase pilote
- Support à distance raisonnable
- Matériel éventuel payé par le restaurant

Ce tarif est volontairement faible pour obtenir un premier cas réel.

## Prix cible après validation

- Setup standard : 790 à 1 490 EUR HT selon import de données et intégrations
- Essentiel : 49 EUR HT / mois
- Pro : 79 EUR HT / mois avec plus d'analyses et d'automatisations

## Garde-fou économique

Après 30 jours, mesurer :
- consommation réelle API IA ;
- temps de support ;
- temps de maintenance ;
- économies mesurées chez le restaurant.

Le tarif doit ensuite couvrir les coûts avec une marge suffisante. Le premier client peut conserver son tarif Founding Kitchen en échange d'un retour terrain et d'un témoignage si les résultats sont bons.
